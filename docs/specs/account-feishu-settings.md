# 账户中心与飞书连接 UI

状态：implementing。自有 web-auth 客户端通过官方 `settings.section` 注册独立飞书页面，官方 UI 与插件保持原样。

账户中心保留身份摘要、用量额度、个人模型、安全与管理员功能；飞书身份绑定从账户折叠区移出，独立侧栏入口与账户中心相邻。模型用量明细默认折叠，使用当前主题语义变量，窄屏不横向溢出，键盘焦点清晰。

独立页复用 `/auth/identities` 与现有绑定/解绑流程，userId 由服务端登录会话确定；不接收其他账号的ID，不改变CSRF或所有权校验。提供刷新、空态、错误提示、解绑处理中状态及现有 `/login` 配对说明。

新增真实 `/auth/feishu-bot` 账号配置API与自建应用表单，保存凭证、校验、启停和网关状态见 [feishu-bots.md](feishu-bots.md)。身份绑定不表示机器人管理权；原部署机器人不自动认领，个人机器人采用独立运行实例并将会话登记到配置账号。

复用 `/opt/dsh/source` 中此前未发布的账户/飞书UI拆分思路，在升级工作树整合；原工作树及其脏改动不覆盖。源码通过不等于已发布；上线另行确认。
