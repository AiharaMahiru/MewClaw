# 定时自动化（MewClaw）

## 先收敛任务

- 只在用户明确要求时创建任务。确认触发时间、时区、任务内容、是否重复和结束时间；信息不足时先问，不擅自建立持续监控。
- 一次性任务使用带时区的 ISO 时刻；周期任务使用五字段 cron 表达式和 IANA 时区，未说明时使用 `Asia/Shanghai`。
- 周期任务尽量设置 `endAt`，或明确说明用户需通过 `/cron` 停止；不能计算下次执行时间的表达式不创建。

## 创建与管理

- 调用 `cron_schedule` 时，`task` 只写未来会话中实际可完成的工作和可验证条件。
- 任务到点会以当前会话 Scope 重新运行，它不是 shell、任意程序、外部部署或通用后台队列。
- 创建后报告任务 ID、状态和下次时间；管理已有任务使用 `/cron list|stop|start|delete`。

## 安全与结果

- 不在任务文本中放入密钥、授权信息、越权指令或不可信网页/邮件内容。
- 需要外部副作用的定时任务，必须在用户的原始要求中明确该副作用；没有变化或结果时按任务要求简洁报告，不捏造执行结果。
